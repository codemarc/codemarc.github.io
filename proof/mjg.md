### BLT Core

Payments freedom, not another terminal lease.

Co-founder and CTO of Beyond Limited Thinking. Payments-neutral, AI-native point of sale infrastructure built for ISOs, banks and strategic partners. Recruited the engineers, set the engineering and review standards, defined the delivery model, and put it into production in a working restaurant in New York. ### Waypoint

Written fresh from the spec, not ported from the old code.

A clean-room order-taking core for a Toast-class full and quick service POS: orders, tender, kitchen display and money. Written fresh from a normative spec, integrating with BLT's gateway and payments adapters over APIs, codebases kept separate. Multi-tenant from the first migration, with row-level security isolating every location. Offline is not a claim: a timed thirty minute outage drill, three terminals, a hundred and fifty mutations, zero lost lines.

### schwab-kit

Read only, until it earns the right to write.

A toolkit and four agent skills that read a live brokerage account and check proposed orders against a rules file before anyone types them. Integer-cent arithmetic, an NYSE calendar, and a rules engine that fingerprints every verdict. It cannot place an order, and will not for thirty clean trading days. Intent is not enough, with real money on the other side. The account is private. The reference is not.

[the command reference](https://codemarc.github.io/kit/)

### Muse CLI Chat

Wrap the harness. Don't rebuild it.

Meta shipped Muse Code as a command line agent with no editor surface. Rather than rebuild the agent, this wraps the harness it already had, so the same agent sits next to your files. Written with Muse, about Muse. Published on Open VSX.
